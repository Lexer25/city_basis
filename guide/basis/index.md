# Модуль Basis — ядро системы "Артонит Сити"

## Назначение

Модуль **dashboard** предназначен для формирования внешнего облика веб-формы Артонит Сити.  

Модуль **basis** представляет собой фундаментальный базовый модуль для системы **"Артонит Сити"**. Он не является самостоятельным приложением, а служит ядром, на котором строятся все остальные модули.  

### Что предоставляет модуль basis:  

- Базовые контроллеры  
- Модели данных  
- Функции рендеринга меню  
- Интернационализацию (i18n)  
- Шаблоны представлений

## Структура модуля  


basis/  
├── classes/  
│   ├── Controller/  
│   │   ├── Basis.php              # Базовый контроллер (действие index)  
│   │   ├── Check_db_connect.php   # Скрипт проверки подключения к БД (не контроллер)  
│   │   ├── Template.php           # КЛЮЧЕВОЙ: расширенный контроллер шаблонов  
│   │   ├── errorpage.php          # Контроллер страницы ошибок  
│   │   ├── login.php              # Контроллер входа в систему  
│   │   └── logout.php             # Контроллер выхода из системы  
│   ├── Menu/  
│   │   └── Renderer.php           # КЛЮЧЕВОЙ: рендеринг меню с фильтрацией по правам  
│   └── Model/  
│       ├── Parkdb.php             # КЛЮЧЕВАЯ: работа с Firebird БД  
│       ├── Stat.php               # КЛЮЧЕВАЯ: статистика и анализ данных СКУД  
│       └── dbskud.php             # Модель проверки формата RFID карт  
├── config/  
│   ├── menu.php                   # Конфигурация меню (базовые пункты)  
│   └── userguide.php              # Конфигурация для модуля справочной системы  
├── guide/  
│   └── basis/  
│       ├── index.md               # Главная страница документации модуля  
│       ├── configuration.md       # Документация по настройке  
│       ├── examples.md            # Примеры использования (праздники)  
│       └── menu.md                # Документация по меню  
├── i18n/  
│   └── ru.php                     # Русские переводы (интернационализация)  
├── views/  
│   ├── basis/  
│   │   └── basis.php              # Вид главной страницы модуля  
│   ├── errorpage.php              # Вид страницы ошибок  
│   ├── template.php               # КЛЮЧЕВОЙ: главный HTML-шаблон сайта  
│   └── top_menu.php               # Вид верхнего навигационного меню  
├── init.php                       # ТОЧКА ВХОДА: регистрация маршрута и конфигурации  
├── README.md                      # Краткое описание модуля  
└── Auth/  
    └── File.php                   # Драйвер аутентификации (загрузка пользователей из БД СКУД)  


---

## Важно  

> **Примечание:** Модуль `basis` является ядром системы и обязателен для работы всех остальных модулей. Без него функционирование системы "Артонит Сити" невозможно.
