# Модуль Basis — ядро системы "Артонит Сити"

## Назначение

Модуль **dashboard** предназначен для формирования внешнего облика веб-формы Артонит Сити.  

Модуль **basis** представляет собой фундаментальный базовый модуль для системы **"Артонит Сити"**. Он не является самостоятельным приложением, а служит ядром, на котором строятся все остальные модули.  

### Что предоставляет модуль basis:  

- Базовые контроллеры  
- Модели данных  
- Функции рендеринга меню  
- Интернационализацию (i18n)  
- Шаблоны представлений

## Структура модуля  

```
basis/  
├── classes/  
│   ├── Controller/  
│   │   ├── Basis.php              # Базовый контроллер (устаревший?)  
│   │   ├── Check_db_connect.php   # Скрипт проверки БД (не контроллер)  
│   │   ├── errorpage.php          # Контроллер страницы ошибок  
│   │   └── Template.php           # КЛЮЧЕВОЙ: расширенный контроллер шаблонов  
│   ├── Menu/  
│   │   └── Renderer.php           # КЛЮЧЕВОЙ: рендеринг меню с правами  
│   └── Model/  
│       ├── dbskud.php             # Модель для проверки RFID  
│       ├── Parkdb.php             # КЛЮЧЕВАЯ: работа с Firebird БД  
│       └── Stat.php               # КЛЮЧЕВАЯ: статистика и анализ  
├── config/  
│   ├── menu.php                   # Конфигурация меню  
│   └── userguide.php              # Конфиг для модуля справочной системы  
├── guide/basis/                   # Документация (Userguide)  
├── i18n/ru.php                    # Русские переводы  
├── init.php                       # ТОЧКА ВХОДА: регистрация маршрута  
├── README.md  
└── views/  
    ├── basis/basis.php            # Вид страницы по умолчанию  
    ├── errorpage.php              # Вид страницы ошибок  
    ├── template.php               # КЛЮЧЕВОЙ: главный шаблон сайта  
    └── top_menu.php               # Вид верхнего меню  
```

---

## Ключевые компоненты  

| Компонент | Путь | Описание |  
|-----------|------|----------|  
| **Template.php** | `classes/Controller/` | Расширенный контроллер шаблонов |  
| **Renderer.php** | `classes/Menu/` | Рендеринг меню с учётом прав доступа |  
| **Parkdb.php** | `classes/Model/` | Работа с Firebird БД |  
| **Stat.php** | `classes/Model/` | Статистика и анализ данных |  
| **template.php** | `views/` | Главный шаблон сайта |

## Праздники  

Праздники позволяют сформировать список дат для набора временных зон.  

Проход в дни, указанные в списке **Праздники**, будет разрешён, даже если эти дни не указаны в категории доступа.
