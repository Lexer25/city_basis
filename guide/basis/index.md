# Модуль Basis — ядро системы "Артонит Сити"

## Назначение

Модуль **basis** представляет собой фундаментальный базовый модуль для системы **"Артонит Сити"**. Он не является самостоятельным приложением, а служит ядром, на котором строятся все остальные модули.

### Что предоставляет модуль basis:

- Базовый контроллер `Controller_Template` — от него наследуются контроллеры всех прикладных модулей
- Главный HTML-шаблон и верхнее меню с формой входа
- Функции рендеринга меню с фильтрацией по правам
- Базовый словарь интернационализации (i18n) для всех модулей
- Драйвер аутентификации, берущий пользователей из базы СКУД
- Модели статистики и аналитики СКУД
- Шаблон и логотипы для модуля справочной системы

## Роли файлов

| Файл | Роль |
|---|---|
| `classes/Controller/Template.php` | Базовый контроллер. В `before()` определяет `is_admin`, собирает меню, версию, flash-сообщение, DSN и сведения о текущем модуле |
| `classes/Menu/Renderermenu.php` | Строит HTML меню из конфиг-групп `menu` и `adm`, фильтрует пункты по ролям, сортирует по `order` |
| `classes/Auth/File.php` | Перекрывает файловый драйвер Auth: список пользователей читается из таблицы `people` базы СКУД |
| `classes/Model/Stat.php` | Статистика опроса контроллеров, аналитика отказов, очереди загрузки карт |
| `classes/Model/Parkdb.php` | Сведения о подключённой базе: DSN, путь к файлу, сервер, количество записей, дата первого события |
| `classes/Model/dbskud.php` | Поиск номеров карт в неверном формате |
| `i18n/ru.php` | Базовый словарь. Модули, зарегистрированные позже, могут переопределять его ключи |
| `views/template.php` | Единственный каркас страницы: подключает CSS/JS, выводит `top_menu` и содержимое |
| `views/userguide/template.php` | Модуль `userguide` своего шаблона не содержит, поэтому справка отрисовывается этим файлом |

## Замены классов ядра

Модуль `basis` зарегистрирован в `application/bootstrap.php` раньше модуля `database`, поэтому его файлы в `classes/Kohana/` перекрывают системные.

Переопределения классов фреймворка размещаются в этом модуле, а не в пакетах фреймворка (`system`, `modules/database` и других): исходники фреймворка не изменяются.

- **`classes/Kohana/Database/PDO.php`** — `Database_PDO::query()` для запросов `Database::INSERT` возвращает **только количество вставленных строк** (`array($rowCount)`), без идентификатора вставки. Причина: драйвер Gemini InterBase ODBC не поддерживает `lastInsertId()`, из-за чего вставки в базу СКУД падали с ошибкой «driver does not support lastInsertId()».

  Оригинал `modules/database/classes/Kohana/Database/PDO.php` остаётся нетронутым и служит эталоном для сравнения.

**Следствие:** идентификатор новой записи нельзя получить из результата вставки. В проекте для этого используется генератор Firebird:

~~~
$newId = DB::query(Database::SELECT, 'SELECT GEN_ID(GEN_XXX_ID, 1) as gen FROM RDB$DATABASE')
    ->execute(Database::instance('fb'))
    ->get('GEN');
~~~

## Важно

> **Примечание:** Модуль `basis` является ядром системы и обязателен для работы всех остальных модулей. Без него функционирование системы "Артонит Сити" невозможно.

> **Порядок модулей:** `basis` должен быть зарегистрирован в `application/bootstrap.php` раньше остальных прикладных модулей. Если какой-либо модуль, стоящий выше в списке, определит класс `Controller_Template`, он перекроет базовый контроллер всего приложения.
