## Модули

Модуль представляет собой набор файлов определенной структуру.

├── config/

├── guide/  						#папка для документации

│       ├── index.md               # Главная страница документации модуля  
│       ├── configuration.md       # Документация по настройке  
│       ├── examples.md            # Примеры использования (праздники)

### Настройка.
Модуль должен быть зарегистрирован в файле ..\application\bootstrap.php  
Kohana::modules(array(
	...
	 '<имя модуля>' => MODPATH.'имя модуля',//комментарий
	 'floorplan' => MODPATH.'floorplan',//планировки
	//'mancard' => MODPATH.'mancard',//Менеджер пропусков
	));
	
В указанном выше примере указана регистрация модуля модуль 'floorplan'.  
Модуль можно отключить, указав в начале //, как для модуля mancard.
